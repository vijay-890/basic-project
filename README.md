My Basic HTML Practice Project
This is a simple practice project I created to learn and experiment with various HTML5 elements. The goal of this project is to understand how to structure a webpage, handle user inputs, and organize content.

🎯 What I practiced:
Structural Tags: Using <header>, <section>, and <div> for layout.

Forms: Creating user input fields for name, email, and password.

Interactive Elements: Using <details> and <summary> to create collapsible content.

Lists & Media: Working with <ul>, <li>, <figure>, and <img> tags.

Navigation: Using anchor (<a>) tags to link to different sections of the same page.

🛠 Tech Stack
HTML5 (Pure HTML)

🚀 How to view it
Download the code or clone the repository.

Open the index.html file in any web browser.

💡 Learning Notes
This project helped me understand the importance of semantic HTML and how elements like label and input work together.

Next, I plan to learn CSS to make this page look professional!
